COCONUSA - Website katalog revisi
================================

CARA MELIHAT:
- Buka index.html di Chrome/Edge/Firefox.
- Klik cover atau nama produk untuk membuka halaman detail produk.
- Pada halaman detail, klik salah satu dari 6 thumbnail; gunakan tombol panah untuk melihat foto berikutnya.
- Klik foto besar untuk menampilkan galeri fullscreen.

CARA MENGUPLOAD:
- Upload seluruh isi folder ini (index.html, folder produk/, dan folder assets/) ke root hosting public_html/ Anda.
- Pertahankan struktur folder; jangan hanya mengupload index.html karena foto dan halaman produk terpisah.
- Jika menggunakan Netlify, upload folder keseluruhannya.

KONTEN DAN CATATAN:
- Menggunakan materi foto produk dari HTML asli yang Anda sediakan; setiap produk memiliki 6 foto.
- Dua kontak WhatsApp dipertahankan dari website sebelumnya.
- Harga/stok tidak dikarang dan bisa ditanyakan via WhatsApp.
- Klaim seperti bebas tanin, Low EC, dan 6x serta bonus mengikuti materi produk, belum dibuktikan dengan laporan uji independen.
- Produk “1 kg netto 1 liter” dipertahankan penamaannya; verifikasi satuan dan isi sebenarnya sebelum publikasi.
- Penjelasan umum cocopeat menggunakan publikasi UF IFAS, RHS, Oklahoma State University, dan artikel Heliyon; tautan tampil di halaman referensi.

FILE:
- index.html: halaman depan
- produk/*.html: empat halaman detail produk
- assets/*.webp: gambar yang dikompresi dengan tetap mempertahankan teks dalam foto
- assets/style.css: desain
- assets/app.js: navigasi/galeri foto
- assets/favicon.svg: ikon

Website dibuat tanpa sistem pembayaran atau database. Pesanan diarahkan ke WhatsApp.


REVISI FOTO TANPA CROP (16 Oktober 2026)
- Seluruh foto pada katalog, banner, panduan, galeri, thumbnail, dan rekomendasi ditampilkan utuh dengan object-fit: contain.
- Label yang sebelumnya menutupi gambar dipindahkan ke bawah foto.
- Ruang kosong di beberapa sisi gambar adalah normal agar foto tidak terpotong.
- Untuk update GitHub Pages: upload ulang seluruh isi folder website dan pilih replace file yang sudah ada.
